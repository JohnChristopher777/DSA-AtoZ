# DSA Practice Repo

This repository contains my Striver A to Z DSA practice work.

## Purpose

- Track my data structures and algorithms practice in one place
- Keep topic-wise Java solutions organized under `src/`
- Use the repo as a personal progress log while I work through the Striver A to Z sheet

## Folder Layout

- `src/basicmath/` - basic math problems
- `src/hashing/` - hashing practice
- `src/patterns/` - pattern printing problems
- `src/recursion/` - recursion practice
- `src/io/` - practice I/O examples, now ignored from the repo

## Notes

- Java source files are kept under `src/`
- Compiled output in `bin/` is ignored
- The `src/io/` folder is treated as practice-only and is excluded from future commits
